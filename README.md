# Ateliê da Kácia - Sistema de Gestão

Sistema completo de gestão para ateliê de costura, com Kanban, encomendas, clientes, estoque, agenda e financeiro.

## Funcionalidades

- **Dashboard** - Resumo do dia com cards de encomendas, prazos, valores e tarefas
- **Kanban** - Board com 8 colunas e drag & drop (Ideias → Entregue)
- **Encomendas** - Cadastro, filtros por status (andamento, entregues, canceladas)
- **Clientes** - Cadastro, histórico de encomendas e contatos
- **Materiais/Estoque** - Tecidos, aviamentos, materiais e alerta de estoque baixo
- **Agenda** - Prazos de entrega, retiradas, compras e compromissos
- **Financeiro** - A receber, recebido, despesas e lucro mensal

## Como usar

Abra o arquivo `index.html` no navegador. Todos os dados são salvos automaticamente no navegador (localStorage).

## Tecnologias

- HTML5 / CSS3 / JavaScript (vanilla)
- Layout responsivo (mobile-first)
- Drag & Drop nativo + polyfill para touch
- Persistência via localStorage
